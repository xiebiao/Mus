# Mus

**简体中文** | [English](README.en.md)

**轻一点，刚刚好。**

**Mus 是 Logi Options+ 的轻量简化替代工具，目前仅支持 MX Anywhere 3S。**

常驻 macOS 菜单栏，专注侧键快捷操作、滚动方向和滚轮手感。

原生 Swift / SwiftUI · macOS 14+ · 简体中文 / English · MIT

[快速开始](#快速开始) · [使用指南](#使用指南) · [常见问题](#常见问题) · [参与贡献](#参与贡献)

## 为什么是 Mus？

如果你只需要侧键映射和滚轮调节，Mus 提供一个简单、常驻菜单栏的设置入口。它不需要账户、云服务、额外驱动或第三方运行时依赖，设置保存在本机。

Mus 为 MX Anywhere 3S 的日常使用而开发，通过 macOS 标准鼠标事件工作。当前支持范围仅限 MX Anywhere 3S，其他型号尚未纳入支持范围。

## 功能

- **侧键快捷操作**：前进／后退、复制／粘贴、撤销／重做、新建／关闭标签页、调度中心、显示桌面和切换桌面；也支持自定义快捷键、保留原始行为或停用。
- **侧键识别**：按下实际侧键学习按钮编号，适应不同的前后键顺序，并显示位置提示。
- **滚轮调节**：调整滚动速度、最小步长和平滑时长，分别反转纵向与横向滚动。
- **设备信息**：显示系统上报的品牌、型号和连接方式，支持蓝牙及 Logi Bolt 接收器识别。
- **菜单栏常驻**：随时暂停或恢复，关闭窗口后继续运行，可选登录启动。
- **中英文界面**：跟随系统，或手动选择简体中文、English，切换立即生效。
- **本地运行**：无网络请求、遥测或输入历史记录，不监听全局键盘输入。

> 当前为 0.1.0 早期版本。设置作用于所有鼠标的对应侧键及普通滚轮，暂不支持单设备或按应用配置。蓝牙设备识别已在 MX Anywhere 3S 上验证；MX Anywhere 3S 在 Logi Bolt 连接下的完整输入行为仍需实机测试。

## 快速开始

### 从源码构建

需要 macOS 14 或更高版本，以及 Swift 5.9+（Xcode 或 Command Line Tools）。

```sh
git clone https://github.com/xiebiao/Mus.git
cd Mus
bash scripts/build-app.sh
open build/Mus.app
```

构建脚本自动生成图标、编译并签名，产物为 `build/Mus.app`。默认构建本机架构；无需下载外部 Swift 包。长期使用建议先将应用放入“应用程序”目录，再授予权限。

当前构建使用本地 ad-hoc 签名，尚未经过 Apple 公证。

### 授予权限

1. 启动 Mus，点击“打开权限设置”。
2. 在 **系统设置 → 隐私与安全性 → 辅助功能** 中开启 Mus；列表中没有时，用 `+` 添加当前应用。
3. 返回 Mus，点击“我已开启，重新检查”，确认 **事件监听：正在运行**。
4. 关闭其他工具中重叠的侧键映射或滚动处理，再测试 Mus。

关闭窗口后，Mus 会留在菜单栏。点击小鼠图标可打开偏好设置、暂停或退出；登录启动在“使用与权限”中设置。

## 使用指南

### 侧键

默认前侧键为前进 `⌘]`，后侧键为后退 `⌘[`。若按键顺序不对，点击对应行的“识别”，再按那颗侧键。识别期间的点击不会执行映射操作，12 秒无输入会自动取消。

从下拉列表选择动作，或选择“自定义快捷键”录制组合。录制仅在应用内控件获得焦点时进行，按 Escape 取消。

| 系统动作 | 默认快捷键 |
| --- | --- |
| 调度中心 | `Control + ↑` |
| 显示桌面 | `F11` |
| 切换左／右侧桌面 | `Control + ← / →` |

系统动作以 macOS 的快捷键设置为准。若修改过快捷键，可录制自己的组合；桌面切换需要对应方向存在另一个空间。

### 滚轮

“自定义滚动”默认关闭，开启后可调整：

| 参数 | 范围 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 滚动速度 | 0.25–3× | 1× | 缩放每次滚动的距离 |
| 最小步长 | 1–80 像素 | 12 像素 | 设置非零输入的最小距离，再乘速度倍率 |
| 平滑滚动 | 开／关 | 开 | 将位移分散到多个帧 |
| 平滑时长 | 80–600 毫秒 | 200 毫秒 | 越短越跟手，越长越柔和 |

想要更精细的滚动，**优先降低速度**。“最小步长”是下限；系统上报的滚动量已经较大时，单独降低它可能没有明显效果。可从 0.5× 速度、300 毫秒平滑时长开始调整。

纵向、横向反转独立设置，方向以 macOS 当前设置为基准。触控板与 Magic Mouse 的连续滚动保持原样。

### 品牌与连接方式

| 检测结果 | 含义 |
| --- | --- |
| 蓝牙 | 根据设备上报的 Bluetooth / Bluetooth Low Energy 信息识别 |
| Logi Bolt 无线接收器 | 根据 Logitech USB 标识 `046d:c548` 识别 |
| USB 无线接收器 | 设备名称明确标识为接收器 |
| USB（有线或接收器） | 系统只报告 USB，无法可靠区分有线鼠标与其他无线接收器 |

设备信息检测不需要辅助功能权限。**“已连接”与“事件监听正在运行”是两个独立状态。** 检测到接收器不代表配对鼠标在线；Mus 目前不查询 HID++ 配对设备，也不推断其型号。

## 兼容性与限制

- 设置适用于所有匹配的标准鼠标事件，不单独绑定某一只鼠标。
- 不修改左键、右键和中键；每次侧键按下执行一次，不模拟持续按住或连发。
- 暂不支持 DPI、电量、SmartShift、每应用配置或写入鼠标板载设置。
- 滚轮调节改变软件滚动距离，不改变硬件精度。连续／惯性滚动会被跳过，自定义滚动也会保留 Control / Command 配合滚轮的原生操作。
- 其他鼠标工具可能提前转换事件，导致 Mus 无法识别侧键或调整滚轮。
- 移动指针、点击、切换前台应用或更改设置时会停止平滑余量，避免延迟滚动落到新目标。

## 常见问题

### 权限已开启，为什么仍提示等待权限？

确认授权的是当前运行的 Mus，而非旧路径或旧版本。移动应用或重新构建后，本地签名可能使原授权失效。退出 Mus，在辅助功能列表中移除旧条目、重新添加当前应用，然后重新启动并检查。

### 识别到鼠标，为什么快捷键没生效？

确认总开关开启、事件监听正在运行，再通过“识别”确认按钮编号。先用实体键盘测试目标快捷键是否有效，并关闭其他工具重叠的映射。前进／后退等动作的实际效果由前台应用决定。

### 滚轮调节为什么不明显？

确认已开启“自定义滚动”并授予权限，先降低速度。其他平滑工具或部分设备可能将滚轮上报为连续事件，这类事件会被跳过。降低最小步长不一定缩短已有的大幅滚动。

### 从 Tiny Mouse 升级会保留设置吗？

会尝试迁移旧版有效的鼠标设置和界面语言，不覆盖 Mus 已保存的设置。新版应用标识为 `local.mus.app`，权限需重新检查。旧版若开启过登录启动，请关闭旧登录项，避免两个版本同时运行。

### 如何卸载？

先关闭 Mus 的登录启动，退出应用，再删除 `.app`。辅助功能条目可在系统设置中移除；删除应用不会自动清除本地偏好设置。

## 开发

```sh
swift test
bash scripts/build-app.sh

# 只读诊断
build/Mus.app/Contents/MacOS/Mus --self-check
build/Mus.app/Contents/MacOS/Mus --list-mice

# 打包为 ZIP
ditto -c -k --sequesterRsrc --keepParent build/Mus.app build/Mus.zip
```

`--self-check` 检查当前进程；终端与 GUI 应用的权限可能不同，以应用界面为准。`--list-mice` 输出品牌、型号和连接方式，不包含序列号或蓝牙地址。

- `Sources/MouseCore/`：设置、输入变换、快捷键与滚动计算。
- `Sources/Mus/`：界面、事件监听、设备发现、权限及登录项。
- `Tests/`：事件处理、滚动、设备分类、设置迁移和本地化测试。
- `scripts/`：图标生成与应用打包。

更多实现细节见 [开发文档](docs/DEVELOPMENT.md)，手动测试流程见 [验收记录](docs/VALIDATION.md)。构建可通过 `SIGN_IDENTITY` 使用本机已有签名身份；Apple 公证不包含在当前脚本中。
